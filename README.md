# 💻 First Project

> 사용자 경험을 고려한 웹 퍼블리싱 프로젝트

---

## 📖 프로젝트 소개

이 프로젝트는 HTML, CSS, JavaScript를 활용하여  
사용자 친화적인 UI를 구현한 웹 퍼블리싱 프로젝트입니다.  
직관적인 레이아웃과 깔끔한 디자인을 통해 사용자가 쉽게 이용할 수 있도록 제작했습니다.

---

## 🛠️ 사용 기술

- HTML5
- CSS3
- JavaScript

---

## 🎯 주요 기능

- 반응형 웹 구현 (모바일 / 태블릿 / PC 대응)
- hover 및 애니메이션 효과 적용
- 직관적인 UI/UX 설계

---

## 🙋‍♀️ 담당 역할

- 전체 UI 퍼블리싱 100% 담당
- 레이아웃 설계 및 구조 구현
- 사용자 경험을 고려한 인터페이스 제작
